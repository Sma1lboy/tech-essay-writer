# Comparison ("X vs Y") Article Template

## Structure
1. **Hook** — Why this comparison matters now (market shift, new release, common confusion)
2. **Criteria** — What dimensions to evaluate (performance, DX, ecosystem, cost, etc.)
3. **Candidate A deep-dive** — Architecture, strengths, weaknesses, sweet spots
4. **Candidate B deep-dive** — Architecture, strengths, weaknesses, sweet spots
5. **Head-to-head comparison table** — Side-by-side across all criteria
6. **Decision framework** — When to pick each (team size, use case, constraints)
7. **Verdict** — Opinionated recommendation with caveats

## Tone
- Fair, evidence-based, "I've used both — here's what I found"
- Acknowledge that context matters — no universal winner
- Show don't tell — benchmarks, code samples, real trade-offs

## Code Density: Medium (20-30%)

## Target Length: 2000-4000 words

## Reader Promise
"After reading this, you'll know which to pick for YOUR situation"
